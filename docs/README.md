# QCC Dokumentation

Diese Dokumentation beschreibt das bestehende Projekt aus 5 Senior-Rollenperspektiven.
Sie basiert auf:
- Projektcode unter `app/src/main/java/de/ca/qcc/`
- Projektleitfaden `CLAUDE.md` und `AGENTS.md`
- Rollenleitfaeden im Ordner `agents/`

## Rollen-zuordnung (Quelle `agents/`)

- Project Manager -> `agents/1_Senior-Product-Manager.md`
- Business Architect -> `agents/2_Senior-Architect.md`
- Business Analyst -> `agents/3_Senior-Business-Analyst.md`
- Developer -> `agents/6_Senior-Software-Developer.md`
- Tester -> `agents/9_Senior-Tester.md`

## Dokumente

1. `docs/01-project-manager-user-stories.md`
2. `docs/02-business-architect-architecture.md`
3. `docs/03-business-analyst-requirements.md`
4. `docs/04-developer-documentation.md`
5. `docs/05-tester-documentation.md`

## Ziel

- Einheitliche Sicht auf Scope, Architektur, Anforderungen, Implementierung und Teststrategie
- Rueckwirkende Nachvollziehbarkeit von Entscheidungen
- Basis fuer Onboarding, Audit und Weiterentwicklung
